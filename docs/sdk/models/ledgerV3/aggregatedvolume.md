# AggregatedVolume

Per-asset aggregated volume as emitted by `GET /v3/{ledgerName}/volumes`.
Prepared-query `AGGREGATE_VOLUMES` responses (under the `aggregateResult`
envelope of `ExecutePreparedQueryResponse`) use this exact shape:
header-negotiated monetary amounts, a computed `balance`, and `color` always present.


## Example Usage

```typescript
import { AggregatedVolume } from "@formance/formance-sdk/sdk/models/ledgerV3";

let value: AggregatedVolume = {
  asset: "<value>",
  balance: "<value>",
  color: "magenta",
  input: "<value>",
  output: 587979n,
};
```
