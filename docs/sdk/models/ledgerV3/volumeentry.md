# VolumeEntry

A single flat post-commit volume tuple for one (asset, color) bucket.
Input/output are flattened onto the tuple (not nested under a `volumes`
key). The empty color is the uncolored bucket and is always emitted.


## Example Usage

```typescript
import { VolumeEntry } from "@formance/formance-sdk/sdk/models/ledgerV3";

let value: VolumeEntry = {
  asset: "<value>",
  color: "maroon",
  input: 885027n,
  output: "<value>",
};
```
