# Alert

An Alert is the stable, dedup'd record of a failing fingerprint within a
reconciliation period. There is exactly one Alert per
(ruleID, fingerprint, periodID) — within a period, re-opens after resolve
flip the status back to OPEN in place; the same fingerprint failing in a
new period is a separate Alert. For a `continuous`-cadence rule there is
one unbounded period, so it behaves as one Alert per (ruleID, fingerprint).
The full history of transitions lives in alert_event
(see /alerts/{alertID}/events).


## Example Usage

```typescript
import { Alert } from "@formance/formance-sdk/sdk/models/reconciliation";

let value: Alert = {
  ack: {
    at: new Date("2024-08-13T19:29:24.261Z"),
    by: "ops@buildr.com",
  },
  createdAt: new Date("2024-03-15T04:47:26.748Z"),
  fingerprint: "asset:USD/2",
  firstSeenAt: new Date("2025-06-05T01:57:13.142Z"),
  id: "b2849657-4c09-4d6f-acfe-f6a98fb49ade",
  lastEvaluationID: "7e3470aa-2c99-4fed-8371-c8cd326f10d1",
  lastSeenAt: new Date("2025-02-09T05:13:38.859Z"),
  occurrenceCount: 15567,
  periodID: "2026-03",
  ruleID: "edeb3de0-39a7-42b2-8dcd-1919f387101c",
  severity: "low",
  snooze: {
    at: new Date("2024-06-04T06:33:19.154Z"),
    by: "ops@buildr.com",
    until: new Date("2026-05-02T11:42:36.957Z"),
  },
  status: "RESOLVED",
  updatedAt: new Date("2025-07-13T12:44:44.008Z"),
};
```
