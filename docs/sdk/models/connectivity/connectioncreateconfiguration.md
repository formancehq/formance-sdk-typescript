# ConnectionCreateConfiguration

Tenant configuration. `env` and `files` contain literal string values,
persisted by the service. Properties marked
`format: password` by the selected connector schema are stored confidentially
and omitted from read responses. Administrator metadata, binding
and reference objects are never exposed and are rejected on input.

CREATE requires `connector`, `ledger` and exactly one of `version` and
`channel`. Existing instances preserve omitted connector and ledger on
update. An imported instance missing either may assign it through PUT after complete
configuration validation against a currently published release.
Once assigned, either value may be repeated but never changed or cleared.


## Example Usage

```typescript
import { ConnectionCreateConfiguration } from "@formance/formance-sdk/sdk/models/connectivity";

let value: ConnectionCreateConfiguration = {
  connector: "<value>",
  ledger: "<value>",
};
```
