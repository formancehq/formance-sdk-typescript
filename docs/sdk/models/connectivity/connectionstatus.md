# ConnectionStatus

Last recorded service and ingestion outcomes, not live health or observation freshness. Absent when no nonempty status is stored.

## Example Usage

```typescript
import { ConnectionStatus } from "@formance/formance-sdk/sdk/models/connectivity";

let value: ConnectionStatus = {
  lifecycle: "pending",
  suspendedBy: [],
};
```
